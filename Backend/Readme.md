# Proyecto de Métodos Numéricos - 7mo Semestre

Este proyecto contiene una suite de métodos numéricos para encontrar raíces de ecuaciones no lineales, desarrollado como parte del curso de Análisis Numérico. El sistema permite al usuario interactuar mediante consola, visualizar tablas de iteraciones y manejar errores de sintaxis matemática :D

##  Guía de Configuración Local


### 1. Requisitos Previos
* Tener instalado **Python 3.10** o superior.
* Tener instalado **Git** (opcional, para clonar).

### 2. Creación del Entorno Virtual (Recomendado)
Es importante aislar las librerías del proyecto para evitar conflictos con otros programas.

**En Windows:**
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1

**Linux:**
python3 -m venv .venv
source .venv/bin/activate

### 3. Instalacion de dependencias
Una vez activado el entorno (verás el prefijo (.venv) en la terminal), instala las librerías necesarias:
pip install -r requirements.txt

### 4. Ejecucion del programa
python main.py
